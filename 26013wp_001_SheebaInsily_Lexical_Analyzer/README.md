## Project Description

The Lexical Analyzer is implemented in C to analyze a C source file and identify different types of tokens.

## Features

- Identifies header files
- Recognizes keywords and identifiers
- Identifies constants
- Recognizes operators
- Identifies special characters

## Files Included

- `main.c` – Main program
- `lexer.c` – Lexical analysis implementation
- `lexer.h` – Header file containing declarations
- `input.c` – Sample input C program
- `makefile` – Compiles the project
- `Output_Screenshot1.png` to `Output_Screenshot5.png` – Program output screenshots

## Compilation

Run the following command in the project directory:

```bash
make
```

## Execution

```bash
./lexer input.c
```

## Expected Output

The program displays the tokens identified in the input C source file, including keywords, identifiers, constants, operators, and special characters.
