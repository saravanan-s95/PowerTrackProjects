# Inverted Search Using Data Structures

## Description
The Inverted Search project indexes words from multiple text files and stores their occurrences in a searchable database. It uses linked lists and hashing concepts to organize and retrieve word information efficiently.

## Features
- Read and validate multiple input files
- Create an inverted index database
- Display the database
- Update the database
- Search for words
- Save the database to a file

## Technologies Used
- C Programming
- Data Structures
- Singly Linked Lists
- Hashing
- File Handling
- Dynamic Memory Allocation

## Compilation
```bash
make
```

## Execution
```bash
./inverted_search file1.txt file2.txt file3.txt
```

## Menu Operations
1. Create Database
2. Display Database
3. Update Database
4. Search
5. Save Database
6. Exit
