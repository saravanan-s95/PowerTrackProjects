# MP3 Tag Reader

## Student Details

- Name: Sundar
- Batch Number: 26001A

## Project Description

This project is an MP3 Tag Reader implemented in C for ID3 version 2.3 files. The application can read, display, and edit metadata stored inside MP3 files.

## Features

- Display title, artist, album, year, genre, and comment information.
- Edit metadata fields individually.
- Read and extract album artwork from the APIC frame.
- Save the modified metadata to the MP3 file.

## Files Included

- main.c
- edit.c
- view.c
- mp3.h
- types.h
- sample.mp3
- cover.jpg

## How to Run

Compile the source files and execute the generated output file.

## Output

The program displays all available metadata and allows the user to modify the required tag.
