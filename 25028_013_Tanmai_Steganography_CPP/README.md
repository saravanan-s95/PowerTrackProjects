# STEGANOGRAPHY USING C++ (LSB TECHNIQUE)

## Project Description
A C++ application that hides and retrieves secret messages inside BMP images using the Least Significant Bit (LSB) technique.

## Features
- Encode secret text into BMP image
- Decode hidden secret text
- Uses LSB image steganography
- Command-line interface
- Supports BMP image format
