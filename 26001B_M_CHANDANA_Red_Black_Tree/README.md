# Red Black Tree Implementation in C

## Student Information

* **Name:** M Chandana
* **Project Title:** Red Black Tree
* **Language:** C

## Project Description

This project implements a Red Black Tree, a self-balancing binary search tree. The program supports insertion, deletion, tree rotations, balancing (fix-up operations), finding minimum and maximum elements, and displaying the tree.

## Files Included

* main.c
* main.h
* insert.c
* insert_fix.c
* delete.c
* delete_fixup.c
* delete_min.c
* delete_max.c
* rotate.c
* find_min.c
* find_max.c
* display.c
* validate.c
* makefile

## Compilation

```bash
make
```

## Execution

```bash
./a.out 10 20 30 15 5
```

## Sample Output

```
5(R) 10(B) 15(R) 20(B) 30(B)
```

## Features

* Red Black Tree insertion
* Red Black Tree deletion
* Automatic tree balancing
* Find minimum and maximum node
* Minimum and maximum node deletion
* Tree traversal and display
