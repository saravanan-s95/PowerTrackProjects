# Digital Alarm Clock

## Overview
Digital Alarm Clock developed using PIC16F877A microcontroller.

## Features
- Real-Time Clock using DS1307
- Time and Date display
- Set Time
- Set Date
- Set Alarm
- EEPROM storage
- 16x2 CLCD interface
- Matrix Keypad interface

## Hardware
- PIC16F877A
- DS1307 RTC
- 24Cxx EEPROM
- 16x2 CLCD
- Matrix Keypad

## Software
- MPLAB X IDE
- XC8 Compiler
