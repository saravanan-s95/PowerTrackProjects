# HTML to Source Code Converter

Name: Potnuru Tanmai
Batch Number: 25028

## Description
This project converts C source code into an HTML file with syntax highlighting. It highlights keywords, comments, strings, header files, numeric constants, and preprocessor directives to improve code readability in a web browser.

## Features
- Converts C source code to HTML
- Highlights C keywords
- Highlights comments
- Highlights string and character literals
- Highlights header files
- Highlights numeric constants
- Supports preprocessor directives
- Generates a browser-friendly HTML output

## Files Included
- Source Code (.c and .h files)
- Makefile
- styles.css
- Project Report
- Output Screenshot
