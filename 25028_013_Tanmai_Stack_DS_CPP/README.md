# STACK DATA STRUCTURES USING C++

Name: Potnuru Tanmai

Batch Number: 25028

## Project Description

This project implements Stack Data Structure operations in C++ using arrays and linked lists. It also demonstrates applications of stacks such as balanced parentheses checking, infix to postfix conversion, postfix evaluation, and expression handling through a menu-driven interface.

## Features

- Stack using Array
- Stack using Linked List
- Push Operation
- Pop Operation
- Peek Operation
- Display Stack
- Parentheses Matching
- Infix to Postfix Conversion
- Postfix Expression Evaluation
- Menu Driven Program
