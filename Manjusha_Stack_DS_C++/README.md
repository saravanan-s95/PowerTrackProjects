# Stack Data Structure in C++

## Description

This project implements a **Stack Data Structure using C++**. A stack is a linear data structure that follows the **LIFO (Last In, First Out)** principle, where the element inserted last is removed first.

The project implements the basic stack operations along with additional functionalities such as searching, reversing the stack, and finding the size of the stack.

## Features

* **Push** – Inserts an element at the top of the stack.
* **Pop** – Removes the top element from the stack.
* **Peek** – Displays the top element without removing it.
* **Display** – Displays all the elements present in the stack.
* **Search** – Searches for a particular element in the stack.
* **Reverse** – Reverses the order of elements in the stack.
* **Size** – Returns the number of elements currently present in the stack.

## Operations

### Push

Adds a new element to the top of the stack.

```text
Before:  10 → 20 → 30
Push:    40

After:   10 → 20 → 30 → 40
                         ↑
                        TOP
```

### Pop

Removes the element from the top of the stack.

```text
Before:  10 → 20 → 30 → 40
                         ↑
                        TOP

After:   10 → 20 → 30
                    ↑
                   TOP
```

### Peek

Returns the top element without removing it from the stack.

### Display

Displays all the elements currently present in the stack.

### Search

Searches for a specified element and indicates whether the element is present in the stack.

### Reverse

Reverses the order of elements in the stack, making the bottom element the new top element.

### Size

Returns the total number of elements currently present in the stack.
