
# Digital Timer

## Project Description
The Digital Timer is an embedded systems project developed using the PIC16F877A microcontroller. It demonstrates timer-based programming and digital display interfacing using Embedded C.

## Hardware Requirements
- PIC16F877A Microcontroller
- Seven Segment Displays
- Push Buttons
- Power Supply

## Software Requirements
- MPLAB X IDE
- MPLAB XC8 Compiler

## Programming Language
- Embedded C

## Features
- Digital time display
- Timer-based operation
- Microcontroller-based implementation

## Project Structure
- main.c - Main program
- Header files - Register and function declarations
- Source files - Program implementation
