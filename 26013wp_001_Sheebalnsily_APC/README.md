# Arbitrary Precision Calculator (APC)

## Description
The Arbitrary Precision Calculator performs arithmetic operations on large numbers beyond the limits of standard C data types.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Command-line argument handling

## Technologies Used
- C Programming
- Linked Lists
- Dynamic Memory Allocation
- Pointers and Functions
- Makefile

## Compilation
```bash
make
```

## Execution
```bash
./apc 123456789 + 987654321
```

## Sample Output
```text
Result: 1111111110
```
