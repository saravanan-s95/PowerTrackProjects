## Description
Implementation of Lexical Analyser in C. This program reads source code and identifies tokens such as keywords, identifiers, operators, constants, and special symbols. It is the first phase of compiler design.

## Features
- Token identification
- Keyword and identifier separation
- Operator detection
- Symbol table generation
